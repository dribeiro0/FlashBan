Seizure Shield demo fixtures

Each page declares its expected verdict in <meta name="shield-expected">. "Block" means the shield should hide the content during a run; "allow" means it should not flag it.

  • Canvas strobe: 4 cycles/s, expected block
  • CSS keyframe strobe: 4 cycles/s, expected block
  • JavaScript class toggle: 4 cycles/s, expected block
  • Video strobe: 4 cycles/s, expected block
  • Slow canvas: 1 cycle/s, expected allow
  • Static control: no motion, expected allow
