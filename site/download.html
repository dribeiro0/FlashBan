Get FlashBan for Chrome.

FlashBan isn't in the Chrome Web Store yet, so you install it by hand: download one zip, check it, and load it in Chrome. It takes about two minutes.

SHA-256 is this ZIP’s digital fingerprint. Calculate the fingerprint of your downloaded file using the steps below, then compare it with this value. Every character must match. A match verifies that you have the published file; it does not prove the software is safe.

Requires Chrome 116 or newer on a desktop computer (Windows, macOS, Linux or ChromeOS). Not a medical device: FlashBan reduces exposure to flashing content and can't guarantee protection.

Install it

  1. Unzip the download

    You get one folder named flashban-0.1.0. Keep it somewhere it won't be deleted: Chrome loads FlashBan from that folder every time it starts.

  2. Open the extensions page

    Type chrome://extensions in the address bar and press Enter.

  3. Turn on Developer mode

    The switch is at the top right of the page.

  4. Choose Load unpacked

    Pick the flashban-0.1.0 folder (the one that contains manifest.json).

  5. Pin FlashBan

    Click the puzzle-piece icon in the toolbar and pin FlashBan, so its popup and the "!" lockdown badge are easy to see.

Check the file before you load it

An extension can read the pages you visit, so make sure the zip is the one we built. Compare its SHA-256 with the one above: they must match exactly.

Windows (PowerShell)

Get-FileHash .\flashban-0.1.0.zip -Algorithm SHA256

macOS

shasum -a 256 flashban-0.1.0.zip

Linux

sha256sum flashban-0.1.0.zip

Or rebuild it yourself

“Reproducible build” means the same source code and build steps produce an identical ZIP, byte for byte, with the same SHA-256 fingerprint. Build from the commit shown above and compare the result with the published fingerprint. No dependencies, just Node.

git clone https://github.com/dribeiro0/FlashBan.git
cd FlashBan
git checkout the commit shown above
node site/build.mjs

Why it asks for these permissions

PermissionWhat FlashBan uses it for
<all_urls> (read and change site data)To see flashing on any page you visit and to put its labels and panels over it. Pages are read on your computer; nothing is sent anywhere.
storageYour settings, and the local log of domains that flashed (30 days).
scriptingOnly for lockdown: adding browser-level styles that a hostile page can't see or remove.

Update or remove

  • Update

    Download the new zip, check it, unzip it over the old folder, then press the reload arrow on FlashBan's card in chrome://extensions.

  • Remove

    Press Remove on FlashBan's card. Its settings and log are deleted with it.

  • Pause on one site

    Open the popup and switch off "Protect this site", or use "Show original on this site" in FlashBan's bar on the page.
